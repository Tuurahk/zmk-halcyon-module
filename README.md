# Official Splitkb.com Halcyon ZMK config

This is the Splitkb Halcyon ZMK module repository. It allows for an external set of ZMK keymaps with or without Halcyon modules to be defined and compiled. Please see the [README in the config repository](https://github.com/splitkb/zmk-halcyon-config) for instructions on how to use this module.
